# Bank-Marketing-ML-Project

Machine learning analysis of bank marketing campaign data to predict deposit subscription using regression, classification, and clustering methods.





**# Bank Marketing Machine Learning Project**



This project analyzes a bank marketing dataset to predict whether a customer will subscribe to a term deposit.  

The work includes:



✅ Data cleaning and preprocessing  

✅ Sampling techniques: Random \& Systematic  

✅ Descriptive analysis and visualizations  

✅ Hypothesis testing  

✅ Simple \& multiple regression  

✅ Classification modeling (Logistic Regression, KNN, Naive Bayes, Decision Tree)  

✅ Best model selection  

✅ Clustering (K-Means \& Hierarchical)  

✅ Git and Version control documentation



The results help improve marketing decision-making and customer targeting.
